# AI-CRM — учёт клиентов и автоматизация B2B-продаж

Минималистичная CRM с AI-агентом: учёт клиентов, ключевые даты, генерация
сообщений и коммерческих предложений.

## Возможности

- **Учёт клиентов** — компании, контакты, должности, статусы сделок, купленные продукты, заметки.
- **Ключевые даты** — дни рождения компаний и контактных лиц, дашборд ближайших дат на 60 дней.
- **AI-агент** — видит всю базу и отвечает по ней: кому позвонить, кого поздравить, какие допродажи возможны.
- **Коммуникации** — генерация коммерческого предложения, сообщения в WhatsApp или поздравления
  под конкретного клиента; отправка через `wa.me` или `mailto`.
- **История взаимодействий** — всё сгенерированное сохраняется в карточку клиента.

## Стек

| Слой | Технология |
|---|---|
| Frontend / API | Next.js 15 (App Router) |
| База данных | Postgres на Railway |
| AI | OpenAI Chat Completions |
| Хостинг | Vercel |

Дизайн следует системе **Ventriloc**: тёплая бумажная палитра, 95% ахроматики,
единственный акцент Ember Orange `#ff682c` только как функциональная пунктуация.

## Переменные окружения

```
OPENAI_API_KEY=sk-...
DATABASE_URL=postgresql://...   # Railway Postgres (public TCP proxy)
OPENAI_MODEL=gpt-4o-mini        # опционально
```

Без `DATABASE_URL` приложение работает на in-memory хранилище — удобно для локального просмотра.

## Локальный запуск

```bash
npm install
npm run dev
```

## Схема данных

`clients` — карточка клиента, `interactions` — история сообщений и КП.
Таблицы создаются автоматически при первом обращении к API.
